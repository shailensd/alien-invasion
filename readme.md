# 🚀 Alien Invasion

A classic 2D arcade-style space shooter built with **Python** and **Pygame**, based on the project from *Python Crash Course* by Eric Matthes.  
Take control of a spaceship, dodge aliens, and blast your way to the top score!

---

## 🎮 Features

- 👾 Alien fleet that moves and drops as it reaches screen edges  
- 🚀 Smooth ship movement and bullet firing  
- 💥 Bullet-alien collision detection   
- 🧠 Score, high score, and level tracking  
- 🕹️ Play button to start or restart the game  
- 📈 Difficulty increases as levels progress


---

## 📦 Getting Started

### Prerequisites

- Python 3.7 or higher
- Pygame

### Installation

```bash
# Clone the repository
git clone https://github.com/shailensd/alien_invasion.git
cd alien_invasion

# (Optional) Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the game
python alien_invasion.py
